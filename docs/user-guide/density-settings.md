# 濃いクラスタの初期値を保存する

レポートごとに、閲覧を開始したときの濃いクラスタの絞り込み条件を保存できます。

1. 管理画面のレポート一覧で、完成したレポートの操作メニュー（…）を開きます。
2. 「可視化設定」を選び、「濃いクラスタの初期値」を入力します。
   - **表示する密度の上位割合（%）**：0〜100。未設定時は20%です。
   - **意見グループの最小サンプル数**：0以上の整数。未設定時は5件です。
3. 「保存」を押し、レポートを開き直して確認します。

「濃いクラスタ」を最初に表示したい場合は、同じダイアログで「散布図（密度）」を表示するチャートに含め、デフォルト表示にも指定してください。条件に合うグループがなければ、濃いクラスタを表示できない場合があります。

これは公開viewerの初期値です。閲覧者が表示中に変えた条件をレポートの設定へ保存する機能ではありません。保存時には他のチャート・表示順・ラベル表示の設定を保持します。

通常の静的サイトは出力し直す必要があります。shell配布物も、変更後の公開レポートJSONを使って組み立て直してください。すでに配布したファイルや開いている画面へ自動的に反映されるものではありません。
