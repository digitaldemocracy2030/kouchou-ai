# 導入を検討する方へ（自治体・非技術者向け）

このページは、広聴AI を自分の組織（自治体・団体など）で使えるか **これから検討する方** に向けた入り口です。コードを読まなくても判断できるよう、導入前に多くの方が気にする次の 3 点にやさしく答えます。

1. **入力したコメントはどこへ送られるのか**（データの扱い）
2. **費用はどれくらいかかるのか**
3. **自分で用意できないとき、どこに相談すればよいのか**

!!! info "広聴AIとは（かんたんに）"
    広聴AI は、たくさんの意見（アンケートやパブリックコメントの自由記述など）を読み込み、似た意見をまとめて **公開レポート（Web ページ）** として見える化するオープンソースのソフトウェアです。出力の読み方は [レポートの読み方](report-reading-guide.md) を参照してください。

---

## 1. 入力したコメントはどこへ送られますか？（データの扱い）

**ここが最も重要です。** 広聴AI は、集めたコメントを分析するために、いくつかの処理で **大規模言語モデル（LLM）** を使います。LLM とは、文章を理解・生成する AI のことです。

既定（標準設定）では、これらの処理は **外部の LLM 事業者（プロバイダ）の API に、コメント本文のテキストを送信して** 実行されます。送信先は、設定で選んだ事業者（OpenAI / Google Gemini など）のサーバーです。

### コメントが外部 API に送られる処理

分析の次の工程で、コメントや、そこから作られたテキストが LLM / 埋め込み API に送られます。

| 工程 | 何をするか | 送られるもの |
| --- | --- | --- |
| 意見抽出 | コメントから主張（意見）を取り出す | コメント本文 |
| 埋め込み（ベクトル化） | 意見を数値ベクトルに変換して「似ている度合い」を測れるようにする | 抽出した意見文 |
| ラベリング | まとまったグループに見出し（名前）を付ける | グループ内の代表的な意見 |
| 概要生成 | レポート全体・各グループの要約文を作る | 抽出した意見 |

!!! note "既定の送信先"
    広聴AI の既定のプロバイダ設定は **OpenAI** です。何も変更しなければ、上記の処理で入力テキストが OpenAI の API に送信されます。レポートを作るときに、管理画面（または CLI の設定）で別のプロバイダ・モデルに変更できます。

### 選べるプロバイダ

レポート作成時に、次のいずれかを選べます。

| プロバイダ設定 | 送信先 | 備考 |
| --- | --- | --- |
| OpenAI（既定） | OpenAI の API | 要 API キー |
| Google Gemini | Google の API | チャットと埋め込みの両方に利用可。要 API キー |
| Azure OpenAI | 契約した Azure OpenAI リソース | 自組織の Azure 契約先に送信 |
| OpenRouter | OpenRouter 経由の各モデル | 要 API キー |
| ローカル LLM | 手元のサーバー（Ollama / LM Studio など） | 外部送信なし（下記参照） |

### 手元（組織内）だけで完結させることもできます

外部にコメントを出したくない場合は、**手元で動く LLM** を使う構成にできます。具体的には、プロバイダを **ローカル LLM**（`local`）にし、かつ **埋め込みも手元で行う設定**（`is_embedded_at_local`）を有効にすると、意見抽出・埋め込み・ラベリング・概要生成のすべてを、外部 API に出さずに手元のマシンで実行できます。

!!! tip "ローカル構成のトレードオフ"
    外部送信をなくせる代わりに、LLM を動かすための **計算資源（相応のメモリや、できれば GPU）** が必要になり、セットアップの難易度も上がります。まずは小さなデータで試し、出力品質と処理時間を確認することをおすすめします。

### 個人情報・要配慮情報の取り扱い

!!! warning "投入前に必ず確認してください"
    - 既定の構成では、入力コメントが **外部の LLM 事業者に送信** されます。氏名・連絡先などの **個人情報（PII）** や、思想・病歴などの **要配慮個人情報** が含まれるデータを、そのまま外部 API に出してよいかは、**庁内（組織内）の規程・個人情報保護の取り扱い** に照らして事前に確認してください。
    - 分析業務を外部に委託する場合は、**委託先・再委託先** が入力データをどう扱うか（どのプロバイダに送るか、保存の有無など）も確認対象です。
    - 外部に出せないデータは、上記の **手元完結（ローカル LLM）構成** を検討するか、匿名化・マスキング済みのデータだけを投入する運用を検討してください。
    - LLM の出力にはバイアスや誤りが含まれ得ます。重要な判断を出力だけに頼らず、必ず内容を検証してください。

## 2. 費用はどれくらいかかりますか？

費用は大きく「ソフトウェア本体」「LLM の利用料」「インフラ（動かす環境）」に分けて考えると見通しが良くなります。

### 本体（ソフトウェア）は無料

広聴AI 本体は **AGPL-3.0 のオープンソース** で、**ライセンス料はかかりません**。業務や研究にも使えます。ライセンス上の注意点（出力 HTML の公開や改造時の条件など）は [ライセンスと結果の公開](license.md) を参照してください。

### かかり得るのは「LLM の利用料」と「インフラ費」

- **LLM API の利用料（外部プロバイダを使う場合）**: OpenAI / Gemini などは **従量課金**（使った分だけ支払う方式）です。料金はおおむね **処理したテキスト量（トークン数）** に比例します。コメントが多いほど、またモデルが高性能なほど、送受信するトークンが増えて費用も増える、という関係です。
- **インフラ費**: 自組織のサーバーやクラウドで動かす場合、その稼働費がかかります。手元の PC で動かし、結果の HTML だけを公開する使い方なら、インフラ費は抑えられます。

!!! note "具体的な金額について"
    実際の料金は **コメント数・選ぶモデル・プロバイダの単価** によって大きく変わり、単価は各社が随時改定します。そのため、このページでは具体的な金額は示しません。目安を知りたい場合は、**「分析したいコメント件数 × 選ぶモデルの単価」** で見積もる、と考えてください。まず少量のデータで一度実行し、実際のトークン使用量から全体を概算するのが確実です。

### ローカル LLM なら API 利用料はかからない

プロバイダを **ローカル LLM** にすると、外部 API への **従量課金は発生しません**。その代わり、前述のとおり LLM を動かす **計算資源** が必要です（GPU を使うと処理を高速化できます）。

!!! tip "無料枠について"
    一部のプロバイダには無料枠がありますが、**1 分あたりのリクエスト数などに厳しい制限** があるのが一般的で、件数の多いデータの一括分析には向きません。試用・小規模検証向けと考えるのが安全です。

## 3. 自分で建てられない場合、どこに相談すればよいですか？

分析を実行するには環境が必要です。技術的な準備が難しい場合も、いくつかの選択肢があります（各選択肢の概要は [トップページの「レポートを作るには」](../index.md#how-to-make-reports) にもまとまっています）。

- **自分で環境を建てる（セルフホスト）**: お使いの OS のセットアップガイドに従います。技術的な知識と計算環境が必要です。
    - [Windows セットアップ](../self-hosting/windows-setup.md) / [Mac セットアップ](../self-hosting/mac-setup.md) / [Linux セットアップ](../self-hosting/linux-setup.md)
    - 分析だけを手早く試したい・研究用途なら [CLI クイックスタート](cli-quickstart.md) も参照できます。
- **建ててくれる人に相談する**: 組織内の情報システム担当者や、導入を支援できる技術者に、環境の用意・運用を相談する方法です。
- **ブラウザで試せる serverless 版を検討する**: Docker などを用意しづらい場合、ブラウザ上で動く [serverless 版](https://github.com/tokoroten/kouchou-ai-serverless) を比較候補にできます。これは **別プロジェクト** で、本体と同一の機能・設定・運用を保証するものではありません。扱えるモデルやデータの取り扱いはリンク先の説明を確認してください。
- **コミュニティに質問する（非技術者も歓迎）**: 「自分の場合はどう始めればよいか」といった相談は、デジタル民主主義2030 の Slack「開発_広聴AI」チャンネルでできます。入口と質問の仕方は [コードを書かずに参加する](../development/contributing.md#コードを書かずに参加する) にまとまっています。環境構築やプログラミングの経験がなくても参加できます。

!!! note "「誰かが運用するサービス（managed）」は現状ありません"
    任意のデータを投入して使える **managed サービスは、現時点では提供されていません**。将来、そうしたサービスを提供する方が現れる余地はあります。現状では、上記のセルフホスト・相談・serverless 版のいずれかが現実的な選択肢です。

---

## まとめ

- **データ**: 既定では入力コメントが外部の LLM 事業者（OpenAI など）に送信される。外部に出せないデータは、ローカル LLM 構成で手元完結にできる。PII・要配慮情報は投入前に庁内規程・委託先を確認する。
- **費用**: 本体は無料（AGPL-3.0）。かかるのは LLM の従量課金とインフラ費。ローカル LLM なら API 利用料はなし（計算資源は必要）。金額はコメント数・モデルで変わるため、少量で試して概算するのが確実。
- **相談先**: セルフホスト／建ててくれる人に相談／serverless 版／コミュニティ（Slack）。managed サービスは現状なし。
