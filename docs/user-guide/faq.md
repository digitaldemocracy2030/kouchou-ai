# よくあるご質問（レポートを読む方・導入を検討する方へ）

このページは、広聴AIが出力した**レポート（Webページ）を読む方**と、**導入を検討している実務者**向けの Q&A です。

!!! info "操作方法・用語の図解はこちら"
    画面の操作や各図の意味は[レポートの見方](how-to-use.md)に詳しくまとめています。レポート画面内にも「レポートの読み方」の案内が常に表示されるので、あわせてご覧ください。

## レポートに出てくる用語がわかりません（クラスタ・散布図・濃い意見など）

よく出てくる言葉の対応は次のとおりです。管理画面・ドキュメントでは「クラスタ」、レポート画面では「意見グループ」のように、同じものを別の言葉で呼んでいる場合があります。

| 言葉 | 意味 |
| --- | --- |
| **意見**（argument） | アップロードされたコメントから、AI が分析対象として取り出した一つひとつの主張。**1 件のコメントから複数の意見が取り出される**ことがあります。 |
| **クラスタ / 意見グループ** | 内容の近い意見を AI が自動でまとめたグループ。ドキュメントや管理画面では「クラスタ」、レポート画面では「意見グループ」と表記します。 |
| **散布図** | 意見を点として平面に配置した図。1 つの点が 1 件の意見です。「全体 / 詳細クラスタ / 濃い意見」の 3 つの見方を切り替えられます。 |
| **縦軸・横軸** | 散布図の軸に特定の意味はありません。AI が多次元の情報を 2 次元に圧縮して並べたもので、**近くにある点ほど内容が似ている**ことを表します。 |
| **濃い意見（濃いクラスタ）** | 似た内容の意見が特にたくさん集まっているグループだけを絞り込んで表示したものです。「多くの人が同じことを言っている話題」を素早く見つけるための見方です。 |
| **階層（階層図）** | 大きなテーマから細かい話題へ、段階的にたどれる見方です。全体像をつかみながら個別の論点も探せます。 |

用語の詳しい説明と図は[レポートの見方](how-to-use.md)を参照してください。

## 結果はどこまで信じていいですか？

**レポートは「結論」ではなく、論点や課題を見つけるための出発点**として扱ってください。AI による要約や分類には誤りや抜けがあり得ます。重要な判断を、レポートの出力だけに頼って下さないでください。

特に次の点に注意してください。

- 集め方・対象・期間によって、含まれる声には**偏り**があります。ここにない意見や、声を届けていない人の存在にも目を向けてください。
- 図の配置やグループ分けは、内容を探すための**手がかり**です。点の位置・距離・グループの大きさだけで、重要度や合意の強さを判断しないでください。
- 気になる論点は、個々の意見を実際に読み、必要に応じて関係者への聞き取りや別の資料で確かめてください。

考え方の詳細は[レポートの読み方・信頼性](report-reading-guide.md)にまとめています。

## 件数や割合はどう読めばいいですか？

**件数は「社会全体の支持率」や「賛成票数」ではありません。** レポートに表示されるのは、集まったコメントから取り出した意見の数であって、賛成した人数でも投票結果でもありません。

- 1 件のコメントから複数の意見が取り出されるため、**意見数とコメント数と人数は一致しません**。意見数・コメント数を人数や賛成数として扱わないでください。
- グループが大きい（点が多い）ことは「正しい」「優先すべき」を意味しません。少数の意見にも重要な指摘が含まれることがあります。

読み取り方の詳細は[レポートの読み方・信頼性](report-reading-guide.md)を参照してください。

## 元の発言（コメント）に遡れますか？

**はい。各意見は、取り出した元のコメントと内部的にひも付いています。** ただし「レポート画面から元の発言をそのまま開けるか」は、作成者の設定によって変わります。

- **ソースリンクが設定されている場合**: 元データに発言の URL（投稿ページなど）が含まれ、作成者がソースリンク機能を有効にしていると、散布図の点をクリックして元のソースを開けます。この機能は既定では無効です。
- **設定されていない場合**: レポートには AI が取り出した「意見」の文が表示され、元コメントの全文はレポートには載りません。元コメントとの突き合わせが必要なときは、作成者（公開元）に問い合わせてください。
- **作成者の手元**: 作成者は「CSV出力モード」で、要約された意見・グループ名・**元のコメント原文**を含む CSV を書き出せます（管理画面からダウンロード）。元発言の照合はこの手元データで行えます。

元コメントと照らし合わせることは、結果を確かめるうえで有効です。詳しくは[レポートの見方](how-to-use.md)の CSV出力モードの項を参照してください。

## 作成・運用にはどれくらい費用がかかりますか？

広聴AIの**ソフトウェア自体は無料のオープンソース**（AGPL-3.0）です。費用がかかるのは、主に次の 2 つです。

- **AI（LLM）の利用料**: 意見の抽出や要約に外部の AI を使う場合、処理したテキスト量に応じた**従量課金（目安）**になります。コメント件数・選んだモデルによって変わります。管理画面には**推定料金**の目安表示があります（あくまで概算で、割引や追加課金は反映しません）。
- **動かす環境の費用**: 自分でサーバーやPCを用意して動かす（セルフホスト）費用です。

具体的な金額は、件数・モデル・環境によって大きく変わるため、ここでは提示しません。モデルと単価の考え方は[モデル一覧・料金](../development/model-catalog.md)を参照してください。なお、**任意のデータを投入できる共用サービス（managed）は現状提供されていません**（[トップページ](../index.md)参照）。導入形態の検討は[導入の検討ガイド](adoption-guide.md)を参照してください。

## 住民・市民の個人情報を入れても大丈夫ですか？

**入力データの取り扱いは、レポートを作成・公開する側の責任**になります。入れる前に、個人を特定できる情報（氏名・連絡先など）は**できるだけ除く（匿名化する）**ことをおすすめします。

判断の前提として、次を理解しておいてください。

- コメントは、作成者が選んだ AI（OpenAI / Azure / Gemini などの外部サービス、またはローカルの AI）に送られて処理されます。**外部サービスに送りたくないデータは、ローカルの AI を使う**などの構成を検討してください。
- 公開レポートに標準で載るのは AI が取り出した「意見」の文で、元コメントの全文ではありません。ただし属性（attribute）やソースリンクを設定すると、付随情報や元発言へのリンクが公開レポートに現れます。**何を公開するかは設定次第**なので、公開前に必ず確認してください。

個人情報・公開範囲の考え方は[信頼性と責任](reliability-and-responsibility.md)と[導入の検討ガイド](adoption-guide.md)に、公開前チェックは[レポートの見方](how-to-use.md)の「公開する前のリンク確認」にまとめています。

## このレポートの責任者は誰ですか？

**そのレポートを作成・公開した人（組織）が責任者**です。広聴AIはあくまで分析・可視化のためのツールで、出力結果を保証するものではありません。

- レポートの作成者名・問い合わせ先・プライバシーポリシー・利用規約は、作成者が設定します。レポートの「作成者情報」欄やフッターで確認できます（設定方法は[レポートの見方](how-to-use.md)参照）。
- 広聴AIは AI（LLM）を利用しており、バイアスや誤りを含む結果を生成しうることが知られています。**重要な決定を下す際は、出力だけに依存せず、必ず内容を検証してください**（[トップページの免責事項](../index.md)）。

レポートの内容についての問い合わせは、作成者情報欄に記載された連絡先へお願いします。考え方の詳細は[信頼性と責任](reliability-and-responsibility.md)を参照してください。
