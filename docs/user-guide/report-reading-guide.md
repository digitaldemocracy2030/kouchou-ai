# レポートの読み方

このページは、**レポートの URL を渡されて開いた方**のためのガイドです。たくさんの意見を AI がまとめた「意見の地図」を、どう読み解けばよいかを説明します。

アプリの立ち上げ方や管理画面の操作は扱いません。画面の操作方法（ズーム・切り替えなど）は [使い方](how-to-use.md) を、分析を自分で動かしたい場合は [CLI クイックスタート](cli-quickstart.md) を、結果の公開・再利用のルールは [ライセンスと結果の公開](license.md) を参照してください。

## このレポートは何を見せているか

広聴 AI のレポートは、**集まったたくさんの意見を AI が読み、似た意見どうしをまとめて、地図のように並べたもの**です。「ブロードリスニング」（broad listening＝多くの声に広く耳を傾ける）という考え方に基づいています。

一つひとつのコメントを最後まで読まなくても、

- どんな話題（意見のまとまり）があるのか
- それぞれにどれくらいの意見が集まっているのか
- 似た意見どうしがどう位置関係にあるのか

を、俯瞰して眺められるようにすることが目的です。

!!! note "これは「全部を見せる要約」ではありません"
    レポートは集まった意見を整理した **見取り図** です。個々の意見の正確なニュアンスは、点を選んで中身を読むことで確認できます（[点の近さには意味がある](#point-distance) を参照）。

## 1 つの点、1 つの意見グループ {#point-and-cluster}

散布図（点がちらばった図）を読むときの基本は、**点**と**意見グループ**の 2 つです。

- **1 つの点 = 1 つの意見**
    - AI が元のコメントから「意見」を取り出した、その 1 件です。
    - 1 件のコメントから複数の意見が取り出されることがあります。そのため **点の数はコメントの件数とは一致しません**（1 つのコメントが複数の点になることがあります）。
    - 点にカーソルを合わせる（スマホはタップ）と、その意見の文章が表示されます。

- **1 つの意見グループ（クラスタ） = 似た意見の集まり**
    - AI が似た意見を自動でまとめ、グループに **名前（見出し）** と **要約** を付けています。
    - 色はグループを見分けるためのものです。色そのものに「良い・悪い」や優先順位の意味はありません。

!!! tip "グループの名前・要約は AI がつけた「見出し」です"
    グループ名や要約は、中身をひとことで表すために AI が生成したものです。気になるグループは、名前だけで判断せず、点を開いて実際の意見を読んでみてください。

## 点の近さには意味がある {#point-distance}

散布図では、**近くにある点どうしは内容が似ていて、遠く離れた点どうしは話題が違う**、と読みます。AI が意見の内容を数値に変換し、「意味の近さ」を 2 次元の平面に配置しているためです。

- 見るのは **点どうしの近さ・遠さ** です。
- 図の **上下・左右の向き（軸）そのものに、決まった意味はありません**。「右だから賛成」「上だから重要」といった読み方はできません。
- かたまって見える部分は、似た意見が多く集まっているところです。

!!! note "近さは「意味の近さ」のおおよその目安"
    たくさんの意見の関係を無理やり平面に押し込んでいるため、距離は厳密な数値ではなく **おおよその目安** です。細かい距離の差を深読みしすぎないようにしてください。

## 数字（件数・割合）の読み方 {#numbers}

各グループには、**そこに入った意見の件数**が表示されます。グループの大きさは、この件数の大きさを表します。

数字を読むときは、次の点に注意してください。

- **件数は「意見の数」であって、人数やコメント数ではありません。** 前述のとおり 1 件のコメントから複数の意見が取り出されることがあります。
- **割合は「今回集まった意見の中での割合」です。** 社会全体や有権者全体の縮図ではありません。どんな人が・どんな経路で意見を寄せたかによって、集まる意見にはかたよりが生じます。
- **件数が多い意見が、正しい・重要とは限りません。** 多く寄せられた声と、少数だが大切な指摘は、別のものとして見てください。

## 散布図の 3 つの見方と階層図 {#views}

同じ分析結果を、**粒度（細かさ）を変えて**見ることができます。散布図には 3 つのモードがあり、ほかにツリー状の「階層図」があります。意味の違いは次のとおりです（切り替えなどの操作は [使い方 — 散布図の操作](how-to-use.md#scatter-operations) を参照）。

| 見方 | 何を見せているか |
| --- | --- |
| **全体** | いちばん大きなくくり（最上層のグループ）だけを表示。まず全体像をつかむための見方です。 |
| **詳細クラスタ** | いちばん細かいくくり（最下層のグループ）を**すべて**表示。話題を細かく見たいときの見方です。 |
| **濃い意見** | 細かいグループのうち、**特にぎゅっと似た意見が集まったもの**だけに絞った見方です（下記参照）。 |
| **階層図** | グループの**入れ子（大きなくくりの中に小さなくくり）の構造**を、ツリーマップで俯瞰する見方です。 |

「全体」と「詳細クラスタ」では、グループを囲む**薄い色の領域**が表示され、そのグループの意見がどの範囲に広がっているかの目安になります。

!!! note "分析のしかたが 1 階層だけのときは"
    クラスタリングが 1 階層しかないレポートでは、「詳細クラスタ」「濃い意見」が選べないことがあります。これは設定上その見方が作れないためで、異常ではありません。

## 「濃い意見」の意味と、少数派への注意 {#dense}

「濃い意見」は、**似た意見が密に集まっているグループだけ**を取り出した見方です。「よく似た声が、まとまって多く上がっている」ところを浮かび上がらせます。

- 細かいグループの中から、**特に凝集度が高く、ある程度の件数があるもの**だけが残ります。
- 各グループが「全体」で見たときの**どの大きなくくりに属するか**も、あわせて示されます。

!!! warning "少数派・小さな声は「濃い意見」から抜け落ちます"
    「濃い意見」は意図的な**絞り込み**です。少人数で散らばった意見や、件数の小さなグループは、この見方には現れません。「濃い意見に出ていない＝重要でない」ではありません。少数の声を見落とさないために、**必ず「全体」や「詳細クラスタ」とあわせて**見てください。

## 結果を鵜呑みにしない {#caveats}

このレポートの作業 — 意見の取り出し、似た意見のグループ分け、グループの名前付けと要約 — は、いずれも **AI（大規模言語モデル）が自動で行っています**。便利な一方で、次のような限界があります。

- **AI の解釈やくせ、取り違えが入りえます。** 意見の切り出し方やグループ分けは、必ずしも人が読んだときと同じにはなりません。
- **グループ名・要約は AI による見出しです。** 判断の根拠にする前に、点を開いて元の意見そのものを確認してください。
- **集めた意見の範囲・集め方によって、結果は変わります。** 同じテーマでも、対象や期間が違えば別の地図になります。

!!! tip "大事な判断に使うときは"
    - 気になるグループは、点を選んで**元の意見を直接読む**。
    - 「全体 / 詳細クラスタ / 濃い意見」など**複数の見方を照合**する。
    - 件数や割合は**おおよその傾向**として扱い、断定の根拠にしない。
    - 不明な点は、レポートの**作成者（発行者）に問い合わせる**（作成者情報は画面に表示されています）。
