# 書籍を読んだ方へ

書籍『[政治・自治体・企業に広がるブロードリスニング](https://broadlisteningbook.com/ja/)』（インプレス）を読んで、広聴AIを触ってみたくなった方のための案内です。

広聴AIには次の 2 つの使い方があります。

- **ブラウザ版**: Web ページを開くだけで使えます。インストールは要りません。**最初に試すならこちらがおすすめです。**
- **サーバ版（本体）**: このリポジトリで開発している、機能がすべてそろった版です。管理画面で複数人でレポートを作り、Web サイトとして公開する運用に向いています。環境の準備（Docker など）が必要です。

ブラウザ版は、サーバ版の分析の流れをブラウザで動くように作り直した別の実装です。手軽に試せる一方で、サーバ版と同じ機能や同じ結果になることは保証していません。まずブラウザ版で「自分のデータからどんな図ができるか」をつかみ、本格的に使うときにサーバ版を検討する、という順番をおすすめします。

## 1. まず、できあがったレポートを見る

レポートを見るだけなら、準備は何も要りません。

- [ブラウザ版のサンプルレポート](https://digitaldemocracy2030.github.io/kouchou-ai-serverless/#/report/sample)を開くと、AI の設定なしで散布図や意見グループを操作できます。
- 書籍に登場した自治体・政党・報道などの公開レポートは、書籍の付録「公開事例一覧」にリンクがあります。
- 図や数字の読み方は [レポートの読み方](user-guide/report-reading-guide.md) にまとめています。

## 2. 自分のデータで試す（ブラウザ版）

[ブラウザ版](https://digitaldemocracy2030.github.io/kouchou-ai-serverless/)を開き、最初の案内から「自分のCSVを分析する」を選びます。

用意するもの:

- **意見の CSV**: 1 行に 1 件の意見が入った表です。Excel やスプレッドシートから CSV で保存できます。年代などの列があれば、レポート上で絞り込みに使えます。
- **AI サービス**: 意見の整理に使う AI を選びます。
    - すでに API キーを持っているサービスがあれば、それを使えます。
    - 新しく用意するなら OpenAI の API キーがおすすめです。ChatGPT の有料プランとは別に、API の支払い設定が必要です（[APIの課金と429エラー](self-hosting/api-billing-and-rate-limits.md)）。
    - API キーなしで試したい場合は、対応する Chrome に内蔵された Gemini Nano を選べます。

試す意見データが手元にないときは、書籍のコラム「SteamレビューとGoogle Mapsレビューで試す広聴AI」のように、身近なレビューを集めて使う方法があります。

!!! note "データの送り先"
    ブラウザ版は、CSV の意見を、選んだ AI サービスにだけ送ります。Gemini Nano を選んだ場合は、パソコンの中で処理します。分析の結果は、そのブラウザの中に保存されます。個人情報や外に出せない内容を含むデータは、送ってよいかを先に確認してください（[導入を検討する方へ](user-guide/adoption-guide.md)）。

使い方の詳しい説明や不具合の報告先は、[ブラウザ版のリポジトリ](https://github.com/digitaldemocracy2030/kouchou-ai-serverless)にあります。

## 3. 本格的に使う（サーバ版）

自治体や団体で継続して使う、複数人で作業する、レポートを Web サイトとして公開する、といった場合はサーバ版を検討してください。

- [始め方の選び方](user-guide/choosing-how-to-start.md): 自分で環境を建てるか、建ててくれる人に相談するか
- [導入を検討する方へ](user-guide/adoption-guide.md): 費用・個人情報・相談先
- [結果の信頼性と責任の所在](user-guide/reliability-and-responsibility.md): 結果をどこまで信じてよいか

## 4. 13章の続きをコードで試す

13章のハンズオン「ミニ広聴AIを作る」の先に進みたい方は、広聴AIの分析部分を Python パッケージとして使えます。

- [CLI クイックスタート](user-guide/cli-quickstart.md): コマンド 1 つで CSV を分析する
- [Python API からの利用](user-guide/import-quickstart.md): 自分のコードから分析の各段階を呼び出す
- [開発者向けガイド](development/contributing.md): 広聴AIの開発に参加する

## 迷ったら
