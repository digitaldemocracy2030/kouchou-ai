# 意見抽出の診断

抽出処理は、正常に空のリストが返った場合と、形式不正・通信失敗を区別します。失敗した回答がある場合は分析を中断し、通常ログには回答IDと例外の種類を表示します。

抽出時に、出力ベースディレクトリの隣の `diagnostics/<report-id>-extraction.jsonl` に原文付きの診断を保存します。標準構成では `outputs/` と同じ階層の `diagnostics/` です。再実行すると同じレポートの診断は上書きします。

- `comment_id` / `comment`: 入力の回答IDと原文。
- `status=empty`: モデルの応答は正常だが、意見を抽出しなかった。入力の性質とプロンプトを照合する。
- `status=error`: 抽出処理が失敗した。`error_type` を確認する。正常な空応答とは異なる。

診断には原文が含まれます。公開レポートの出力先とは分け、通常のレポート配布に含めません。必要な入力だけを手元で確認し、調査終了後は診断ファイルを削除してください。API応答や例外本文は診断へ保存しません。実行ユーザーだけが読める権限で新規作成します。
