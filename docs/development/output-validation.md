# 完成したレポートの参照整合性を確認する

本体・serverless間で結果JSONを受け渡す際や、生成処理を変更した際は、次の読み取り専用コマンドで確認できます。LLMへの通信やファイルの修正は行いません。

```bash
python -m analysis_core.validate_output outputs/example/hierarchical_result.json
```

クラスタ・意見のID重複、親の参照切れ・循環、意見の階層パス、座標や件数の不正値を検査します。終了コードは正常0、整合性の問題1、読込失敗2です。未知の追加フィールドは許容します。

この検査は任意の診断です。既存の分析完了条件を変更しません。ラベル品質・根拠の妥当性・個人情報の有無・可視化全機能への適合を保証するものではありません。状態ファイルは実行経路による差があるため今回の検査に含めません。
