# 狭い画面でのレポート閲覧

## 採用する最小範囲

初期表示を指定していないレポートは、600px以下で階層リストを入口にします。hoverを必要とせず、グループを展開して意見を読めるためです。図は通常の表示切替から選べます。画面回転やウィンドウのリサイズで、利用者が選んだ表示を戻しません。

レポートにdefaultChartが指定されている場合、または有効な表示一覧から階層リストを外している場合は、その指定を優先します。serverless版も狭い画面の最初の入口に既存の階層リストを使います。

幅の閾値は端末の識別ではなく、読める領域の幅による判断です。専用画像の生成や新しいレポート形式は導入しません。散布図の幾何・ラベル密度そのものの改善（#121 / #266）は別の課題です。

## 確認する操作

- 390px程度の画面で開き、階層を展開して意見を読む。
- 図へ切り替え、リサイズしても選択が維持される。
- 明示的なdefaultChart・有効な表示一覧を尊重する。
- 属性フィルターで0件になった状態を確認する。

初期表示の規則は本体・serverlessで揃え、利用者からのフィードバックを受けて幅と既定表示を見直します。
